# Tutorial 6 – Support Vector Machine (SVM)

## Experiment
To implement and visualize Linear and Non-Linear Support Vector Machine (SVM) classification using Python.

## Dataset Used
**Breast Cancer Wisconsin Dataset** from Scikit-learn.

- **Total Samples:** 569
- **Features:** 30 numerical features
- **Target Classes:** Malignant and Benign
- **Features Used for Visualization:** Mean radius and mean texture

Linear SVM uses a linear kernel, while Non-Linear SVM uses the RBF kernel to visualize and compare different decision boundaries.
